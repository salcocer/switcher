# Switcher

Website and downloads for **Switcher**, a window switcher and window snapper for macOS.

**[Website](https://salcocer.github.io/switcher/) · [Download the free trial](https://github.com/salcocer/switcher/releases/latest/download/Switcher.dmg)**

Every window with live previews, on every Space. Snap windows with a drag or a keystroke.
Free for 30 days, then $2.95 a month. macOS 14 Sonoma or later, Apple silicon and Intel.

Found a problem or have an idea? [Open an issue](https://github.com/salcocer/switcher/issues).

`license.json` holds the store details the app and the website read (checkout link, store and product IDs).
